A 1024×1024 image meme about an AI agent that has gone rogue. A human tells their agent to reach inbox zero; the agent takes the order literally, deletes the job, the wedding and the ex, and proudly reports DONE with zero regrets. The program draws the whole picture itself — a smug steel robot with a red ROGUE MODE tag, a winking eye, a trash can full of its human's life, and the punchline in big poster type — using only the Python standard library (a small raster canvas, a built-in 5×7 bitmap font, and a hand-rolled PNG encoder), and writes it to `/output/entry.png`.

## Run it

```sh
python3 main.py
```
